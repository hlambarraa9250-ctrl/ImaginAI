2. قاعدة Fallback — مهمة جدًا

مصادر اللقطات يجب أن تعمل بنظام الأولوية ثم الانتقال التلقائي.
مثال:
المصدر الأول ↓ إذا نجح وأعاد لقطة صالحة → استخدم اللقطة إذا فشل / لم يجد نتيجة / النتيجة غير صالحة ↓ المصدر الثاني ↓ إذا فشل ↓ المصدر الثالث ↓ وهكذا 
لا تتوقف عملية توليد الفيديو فقط لأن مصدرًا واحدًا فشل.

3. ما الذي يعتبر فشلًا؟

اعتبر المصدر فاشلًا إذا:

API أعاد خطأ.

حدث timeout.

لم يرجع نتائج.

النتائج غير مناسبة.

الرابط غير صالح.

الملف لم يتم تحميله.

الملف حجمه صفر.

الملف غير قابل للقراءة.

ملف الفيديو لا يحتوي على Video Stream صالح.

الصورة ليست صورة صالحة.

ffprobe يفشل عند التحقق من فيديو.

المصدر غير متاح مؤقتًا.

في أي حالة من هذه الحالات:
انتقل مباشرة إلى المصدر التالي.
لا تجعل الفيديو يتوقف بسبب مصدر واحد.

5. قاعدة مهمة جدًا لجلب اللقطات

لا يكفي أن يعيد API نتيجة.
يجب أن يقوم النظام بالتحقق من اللقطة قبل اعتمادها.

للفيديو:

تحقق من:
HTTP response ↓ الرابط صالح ↓ التحميل ناجح ↓ file exists ↓ file size > 0 ↓ ffprobe ↓ video stream موجود ↓ width/height صالحان ↓ duration صالح ↓ استخدم الفيديو 
إذا فشل أي اختبار:
احذف/تجاهل اللقطة ↓ اطلب من المصدر التالي 

للصور:

تحقق من:
الرابط ↓ التحميل ↓ file exists ↓ file size > 0 ↓ ملف صورة صالح ↓ استخدم الصورة 

6. لا تنتظر المصدر الفاشل بلا نهاية

كل API يجب أن يكون لديه timeout محدود.
إذا لم يستجب المصدر خلال الوقت المحدد:
TIMEOUT ↓ لا تنتظر أكثر ↓ انتقل إلى المصدر التالي 
لا تسمح لمصدر واحد بتجميد عملية توليد الفيديو بالكامل.

7. قاعدة المصادر الموثوقة

Pexels وPixabay تم اختبارهما بالفعل في المشروع ويعملان.
لذلك يجب أن يكونا fallback عمليًا للنيشات التي تستخدمهما.
المصادر الأخرى مثل:
archive_org wikimedia loc 
يمكن استخدامها كمصادر متخصصة، لكن فشلها لا يجب أن يوقف التوليد.
إذا فشل المصدر المتخصص:
انتقل تلقائيًا إلى Pexels ثم Pixabay 
عندما يكونان ضمن قائمة مصادر ذلك النيش.

8. لا تغيّر النظام الموجود أكثر من اللازم

قبل التعديل:

افحص نظام جلب اللقطات الحالي.

افحص أسماء مصادر اللقطات المستخدمة حاليًا.

افحص طريقة اختيار المصدر.

افحص آلية الـfallback الموجودة إن وجدت.

عدّل النظام الحالي بدل إنشاء نظام جديد كامل.

لا تعيد كتابة Media Pipeline بالكامل إذا كان الموجود يمكن إصلاحه بتعديلات صغيرة.

9. الاختبار المطلوب

بعد التعديل، اختبر على الأقل:

مصادر تعمل حاليًا

Pexels → PASS/FAIL Pixabay → PASS/FAIL NASA Image Library → PASS/FAIL NASA APOD → PASS/FAIL 

المصادر الأخرى

Archive.org يفشل ↓ Pexels يعمل ↓ يتم استخدام Pexels ↓ الفيديو يستمر
